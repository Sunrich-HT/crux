# Brand Assets

`readme-banner.png` is a complete text-to-image artwork generated in one pass through ChatGPT Images on 2026-08-19. It is not assembled from a logo, typography, buttons, or layout code. `social-preview.png` is only a proportional downscale of the same complete artwork.

The standalone project mark remains available as `crux-logo-1024.png`; the installable skill uses its own exports under `skills/crux/assets/`.

## Cover generation prompt

```text
Create one complete, cohesive GitHub README cover image for CRUX, an open-source evidence-governed thinking system. Many conflicting claim fragments and evidence sheets arrive from different directions, pass through one exact central pivot, and leave as one clear forward path. Very wide 5:2 landscape banner, full bleed, strong depth, decisive central focal point, generous safe margins. Premium editorial key art; tactile paper sculpture combined with restrained architectural 3D; luminous off-white technical-paper environment; deep ink shadows; translucent evidence layers; precise cut-paper geometry; a vivid coral decision line. Palette: off-white, charcoal, deep teal, signal coral, with a small cobalt accent. Include the exact word CRUX once in clean bold sans-serif capitals, naturally integrated into the physical scene. No other text, logo card, UI panels, badges, pasted layout, watermark, brains, lightbulbs, scales, chat bubbles, magnifying glasses, mazes, generic network nodes, glowing AI circuitry, gradients, stock-photo aesthetics, or corporate presentation templates.
```
