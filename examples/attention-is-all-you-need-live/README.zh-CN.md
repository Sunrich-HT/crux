# 真实安装实测：《Attention Is All You Need》论文辅导

这不是编写出来的演示对话。2026-08-19，我们从公开 GitHub 仓库安装 Crux，启动一个独立的 Codex CLI 任务，让它读取 Vaswani 等人的原始论文，再连续进行两轮论文辅导。仓库保留完整输入和未经编辑的原始输出。

## 测试材料

- 论文：[Attention Is All You Need](https://arxiv.org/abs/1706.03762)
- 阅读范围：第 3.5 节 `Positional Encoding` 与 Table 3 row (E)
- 测试问题：正弦位置编码为何有助于表达相对位置，以及论文是否真的验证了长度外推
- 运行方式：从 GitHub 安装 `$crux` 后，在独立 Codex CLI 任务中使用 `coach` 模式
- 完整环境和文件哈希：[run-metadata.json](run-metadata.json)

论文 PDF 和全文不收入仓库；运行时直接下载 arXiv 原始 PDF。这样既避免重新分发论文，也让来源版本可以用 PDF 哈希核验。

## 第一轮：学生问了什么

学生没有问泛泛的“帮我总结 Transformer”，而是指出了一个真实的阅读疑点：

> 我理解 self-attention 本身不会区分 token 的先后顺序，所以作者把位置编码加到词向量上。但我还是没真正理解：论文说对于固定偏移 k，PE(pos+k) 可以表示成 PE(pos) 的线性函数，这为什么就意味着注意力能够学习“相对位置”？另外，作者说正弦位置编码可能外推到训练时没见过的更长序列，Table 3 只比较了 learned embedding 和 sinusoid 在开发集上的 BLEU，看起来并没有直接测试长度外推。我的理解哪里对，哪里还混在一起？

[查看第一轮完整输入](prompt-turn-1.md)

## 安装后的 Skill 原样回答

Crux 先把问题拆成三个不能混淆的命题：

1. 正余弦编码在数学上能否表示固定相对位移；
2. 模型训练后是否真的会利用这种结构；
3. 更长序列上的泛化是否经过实验验证。

它给出了“固定偏移对应固定旋转”的必要脚手架，但把最关键的内积化简留给学生：

> 你可以自己补上最关键的一步：计算同一频率下 \(u_p^\top u_q\)，并用三角恒等式化简。然后问自己：结果依赖 \(p,q\) 各自，还是只依赖 \(p-q\)？

同时，它核对 Table 3 后明确指出：开发集上的 25.8 与 25.7 BLEU 只说明两种位置编码结果接近，不能证明长度外推。

[查看第一轮未经编辑的完整回答](raw-turn-1.md)

## 第二轮：学生完成关键推理

学生算出：

\[
u_p^\top u_q = \cos(\omega(p-q))
\]

并进一步注意到，真实 Transformer 中还存在内容-内容、内容-位置、位置-内容和位置-位置交叉项，因此“原始位置向量内积依赖相对距离”只是可利用的结构，不是训练后行为的保证。

[查看第二轮完整输入](prompt-turn-2.md)

Crux 随后确认这条推理，补充了方向不可辨识和投影矩阵结构的限制，最后将阅读结论压缩成一句话：

> sinusoidal PE 让相对位置在表示上容易被读出；Table 3 只说明它没有明显损害常规翻译表现，并没有证明模型确实按相对位置注意，更没有证明长度外推。

[查看第二轮未经编辑的完整回答](raw-turn-2.md)

## 这次实测说明什么

这一次运行做到了：

- 依据原论文而不是二手总结回答；
- 区分作者测量到的结果、数学动机和作者尚未验证的推断；
- 第一轮只保留一个有意义的学生任务，第二轮在学生作答后继续收敛；
- 没有为了“苏格拉底式”而连续抛出一串问题。

它也暴露了真实不足：

- 第一轮已经给出了二维旋转矩阵，脚手架偏多；更严格的导师可能先让学生自己写和角公式；
- 原始回答中的本地文件链接只在当次运行环境有效，仓库因此同时保留原论文 URL；
- 单独安装 Skill 约束的是模型行为，不是硬权限边界。需要强制披露上限时，仍应接入仓库中的确定性 policy core。

这不是“准确率”测试。两轮对话没有足够样本，也没有盲评标注者，不能据此声称学习提升百分比。它证明的是：安装流程真实可执行，回答确实来自已安装 Skill，并且全过程可审计。长期学习效果需要预注册、多论文、多模型和人工评分的对照实验。

## 如何复现

安装：

```bash
npx skills add Sunrich-HT/crux --global --agent codex --skill crux --yes --copy
```

从 arXiv 下载论文并转换为文本后，在同一目录运行：

```bash
codex exec --sandbox read-only --skip-git-repo-check "$(cat prompt-turn-1.md)"
```

复现需要可用的 Codex 登录或 API 配置。模型服务会随时间更新，因此新的措辞不保证逐字相同；[run-metadata.json](run-metadata.json) 中的哈希用于核验本次存档没有被改写。
