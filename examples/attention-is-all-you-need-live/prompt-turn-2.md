我算了一下：

u_p^T u_q = sin(ωp)sin(ωq) + cos(ωp)cos(ωq) = cos(ω(p-q))。

所以在单个频率的这一对维度上，位置编码的内积只取决于相对距离 p-q，而不分别取决于 p 和 q。多个频率就会给出多个尺度上的相对距离特征。

但真实 Transformer 里是 token embedding 与 positional encoding 相加之后，再分别经过 W_Q、W_K。这样注意力分数里还会有内容-内容、内容-位置、位置-内容等交叉项，所以“原始位置向量的内积只依赖相对距离”只能说明模型有机会利用这种结构，不能证明训练后一定只按相对距离注意。我这样理解对吗？请继续像论文导师一样反馈，并告诉我读这段时最终应该记住什么。
