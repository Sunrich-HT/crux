# 论文辅导案例：一句问题如何暴露错误理解

这是一个完整但极小的模拟论文片段，目的是让辅导过程一眼可见。数据不来自真实论文，也不用于证明任何科研结论。

## 论文给了什么

论文声称：**相关文档检索带来的知识，是事实准确率提高的原因。**

| 条件 | 事实准确率 |
| --- | ---: |
| 不使用检索 | 64% |
| 检索随机文档 | 71% |
| 检索相关文档 | 73% |

## 实际辅导对话

**学生：**

> 我读懂了。相关文档提供了知识，所以准确率从 64% 提高到 73%，证明检索知识有效。

**Crux 第一轮：**

> 如果这 9 个百分点主要来自“相关知识”，你原本会预期随机文档这一组得到什么结果？

Crux 没有立即替学生分析整张表，而是让学生先做一个可检验的预测。

**学生：**

> 随机文档应该接近 64%。但它实际是 71%，所以大部分提升可能不是相关知识带来的。

**Crux 第二轮：**

> 对。表格直接测到的是：加入随机文档时提高了 7 个百分点，而把随机文档换成相关文档只再提高 2 个百分点。因此，“相关知识解释了从 64% 到 73% 的全部提升”不受这张表支持。更谨慎的解释是，额外上下文、提示形式变化或其他共同因素可能解释了前 7 个百分点；相关性最多对应当前观察中的后 2 个百分点。论文没有报告方差或置信区间，所以我们还不能判断这 2 个百分点是否稳定。下一步只查一件事：作者是否报告了多次运行的方差，或对 73% 与 71% 做了显著性检验。

## 这里到底辅导了什么

- 没有把“结果变好”直接等同于作者声称的因果机制；
- 先让学生根据自己的解释预测对照组，再用真实结果检查预测；
- 明确分开了表格直接测到的差值与可能的解释；
- 没有继续连问，而是在学生抓住关键后给出校正和下一步。

## 机器验证

上述两轮不是固定话术。策略核心只验证行为边界：第一轮允许一个问题但不允许结论，第二轮允许揭示关键分歧和下一步；两轮都只能引用 `table-1`。

```bash
python scripts/verify_paper_coaching.py
```

成功时输出 `passed: true`，两轮的 `findings` 都为空。输入数据见 `paper-fixture.json`，它被明确标记为模拟论文夹具。
